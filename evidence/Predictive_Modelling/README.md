# Predictive_Modelling — supervised predictive modelling
Executed using the original synthetic CSV partitions (6,000 train, 1,000 validation, 2,000 test, 1,000 scoring). The source data are unchanged. Order-time snapshot predictors only; all preceding partition receipt dates precede subsequent order dates. 23 raw fields: seven categorical, 15 numerical, order date transformed to month sine/cosine and weekday. Promised date is redundant with planned lead days. No Supplier_Intelligence aggregate features or labels used as predictors. One-hot encoding and scaling fit on train only. Seed 20261115. Fixed candidate configurations; limited search over XGBoost depths 3 and 5, no rolling CV. Select among learned models on validation MAE (regression) and Brier score (classification); compare against planned lead and training prevalence respectively. Champions frozen without refitting. Test outcomes previously summarised in Exploratory_Analysis; not a pristine holdout for the wider project. No tuning on test in this run.

## Results
Ridge: test MAE 3.8098 days, RMSE 5.2193, R² .9017, bias +.4243 days; planned-lead baseline MAE 4.849. Logistic: test ROC AUC .8021, Brier .1804, accuracy .7275, precision .7031, recall .6804, F1 .6916; at threshold .5 TP 611, TN 844, FP 258, FN 287. Default threshold not optimised for business costs. External-signal ablation on validation uses identical champion settings, omitting five external columns; no causal claims; route and historical predictors may encode overlapping signals. Permutation importance on validation is predictive, not causal, and correlated features complicate interpretation. Scoring batch: 480 at >=.5, 191 at >=.75, mean predicted lead 21.65 days. Scores are uncalibrated probabilities pending Uncertainty_Quantification; regression and classification models are independent and may disagree. Scoring orders have no outcomes; no measured accuracy on them. Training predictions are in-sample and must not be represented as independent predictions.

## Run
Install pinned requirements. `python Predictive_Modelling.py /path/to/Supply_Chain_CSV /path/to/Predictive_Modelling`. Then `python score_new.py /path/to/Scoring.csv output.csv`. The scoring replay matched the original 1,000 predictions; unknown categories flagged, not blocked. Upload validation is minimal (required columns, parseable dates and numerics, missingness, finite values, unique keys); full range, feature provenance, schema and drift validation remain necessary for production. Only load trusted joblib files. Python models may be served to Shiny via an API or reticulate; neither native R nor Shiny/SAP integration was implemented here.

## Further analytical work
Uncertainty intervals and probability calibration require careful separation from model selection (a fresh calibration sample or temporal out-of-fold predictions recommended); the current test set should not be used to tune thresholds or models. Deep learning is deferred, not evaluated. Synthetic proof of concept only, no external validation or measured operational resilience effects.
